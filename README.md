# ☀️ SolarTech

Landing page responsiva desenvolvida para uma empresa fictícia de energia solar. O projeto foi criado com foco em **desenvolvimento front-end**, responsividade e experiência do usuário em diferentes tamanhos de tela.

## 🌐 Projeto online

O projeto está publicado no GitHub Pages:

👉 [Acessar SolarTech](https://rodrigues-git.github.io/SolarTech/)

## 💻 Tecnologias

* HTML5
* CSS3
* JavaScript

## 📱 Mobile First

O projeto foi desenvolvido utilizando a abordagem **Mobile First**, começando pela estrutura e estilização para dispositivos móveis e expandindo o layout para telas maiores através de **Media Queries**.

Essa abordagem permitiu construir uma interface responsiva mantendo boa organização dos elementos tanto no mobile quanto no desktop.

## 🎨 Layout e responsividade

Durante o desenvolvimento foram utilizadas técnicas como:

* **Flexbox** para alinhamento e distribuição de elementos;
* **CSS Grid Layout** para estruturas mais complexas;
* **Media Queries** para adaptação entre diferentes tamanhos de tela;
* posicionamento relativo e absoluto para composição de elementos visuais;
* transições CSS;
* navegação com rolagem suave;
* organização responsiva de cards, formulários e seções.

## ⚙️ JavaScript

O JavaScript foi utilizado para adicionar interatividade à página, trabalhando conceitos como:

* manipulação do **DOM**;
* tratamento de eventos com `addEventListener`;
* manipulação de classes com `classList`;
* menus responsivos;
* FAQ expansível;
* slider de serviços na versão mobile;
* calculadora de economia;
* manipulação de formulários e eventos de `submit`;
* alteração dinâmica de conteúdo da página.

## 🎯 Objetivo

O SolarTech foi desenvolvido como projeto de estudo e portfólio, com o objetivo de aplicar na prática conceitos fundamentais de desenvolvimento front-end, principalmente **HTML semântico, responsividade, Mobile First, CSS Grid, Flexbox e JavaScript para manipulação do DOM**.

O projeto também buscou transformar um layout completo em uma interface funcional e adaptável sem utilização de frameworks front-end.
